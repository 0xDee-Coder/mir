# mirKlokV3

## Installation

1. Clone this repository

```bash
git clone https://github.com/0xDee-Coder/mir.git
cd mir
```
- set the ref_code & 2captcha Key in the .env file
```bash
nano .env
```
2. Install dependencies
```bash
npm install
```
3. Fill Data and Proxy (Optional)

```bash
nano proxy.txt
```
5. stores account privateKeys  `One Per Line`
```bash
nano privateKeys.txt
```

6. A few sample questions are included, but you should not use the default ones.
- You can generate your own using AI tools like: poe.com groq.com or chatgpt

7. Run Auto Ref (Optional)
```bash
node autoref
```
- run node main.
```bash
node main
```
